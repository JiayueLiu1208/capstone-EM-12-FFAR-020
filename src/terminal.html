    Placeholder

    A four-axis robotic arm that turns typed text into pen strokes on paper.

    The base turns (θ1), the shoulder and elbow pitch the two links (θ2, θ3), and the wrist (θ4) keeps the pen pointing straight down. All four joints are hobby servos. A planner on the laptop turns text into single-line strokes, solves the joint angles for every point, and streams them to an Arduino over USB serial.

    The display above runs the same planner and kinematics, drawn from directly above: the elbow is a single hinge, so both links always line up with the pen. The G-code on the right is generated from the real motion plan as the arm moves: G0 travels with the pen 12 mm up, G1 Z0 puts it down, G1 X Y draws.

    ./plot --explain

    Pipeline

    1. [1/5]text: read the word from the prompt or the command line
    2. [2/5]glyphs: map each letter to single-line strokes on a 10-unit cap height
    3. [3/5]plan: order strokes, reverse them where it cuts pen-up travel, resample every 0.5 mm
    4. [4/5]solve: inverse kinematics, (x, y, z) → (θ1, θ2, θ3, θ4) for every sample
    5. [5/5]drive: angles → PWM on four channels at 50 Hz; pen lifts 12 mm in z between strokes

    Kinematics

    θ1 = atan2(x, y) # base
    r = hypot(x, y); h = z + Lt − h0 # Lt = h0, so h = z
    β = acos(hypot(r, h) / (2·L)) # equal links: isosceles
    θ2 = atan2(h, r) + β; θ3 = −2·β # elbow up
    θ4 = −90° − θ2 − θ3 # pen stays vertical
    θ1=0.00°θ2=0.00°θ3=0.00°θ4=0.00°xyz=0, 0, 0mmpen=UP
