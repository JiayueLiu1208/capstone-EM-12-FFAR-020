Status: ready

A four-axis robotic arm that turns typed text into ink on paper.

A turning base, a shoulder and an elbow carry the pen; a wrist keeps it pointing straight down. A small planner works out every joint angle along the way. This page documents how it was designed, built and tuned.

A

Overview

Scale 1:1

The arm is a four-axis articulated manipulator. The base turns the whole arm about a vertical axis (θ₁), the shoulder and elbow pitch the two links (θ₂, θ₃), and the wrist (θ₄) counter-rotates so the pen always points straight down at the paper. Every joint is a hobby servo, so the machine can be built from printed parts and a microcontroller.

To write, the software turns each character into single-line strokes, orders them to keep pen-up travel short, and solves all four joint angles for every point along the way. Between strokes the arm lifts the pen 12 mm in Z rather than using a separate lift mechanism.

The aim of the project was to get from a typed word to a legible, repeatable result with inexpensive parts, and to understand where the error comes from when it isn't.

B

Kinematics

Not to scale

Inverse kinematics, equal links L, pen vertical, elbow up

(1)θ₁ = atan2(x, y)
(2)r = √(x² + y²), h = z + Lₜ − h₀ = z
(3)β = arccos(√(r² + h²) / 2L)
(4)θ₂ = atan2(h, r) + β, θ₃ = −2β
(5)θ₄ = −90° − θ₂ − θ₃

The base angle comes straight from the target's bearing. With two equal links, shoulder, elbow and wrist form an isosceles triangle, so a single arccos solves it. The pen hangs Lₜ = h₀ below the wrist, so with the pen on the paper the wrist is level with the shoulder and, seen from above, the elbow sits exactly halfway to the pen. C

From keystroke to ink

Process flow

  1. Text input

    A word typed into the web interface or passed on the command line.

  2. Stroke font

    Every glyph is stored as single-line strokes on a 10-unit cap height, so the pen traces each line once.

  3. Path planner

    Strokes are ordered and reversed where it shortens pen-up travel, then resampled every 0.5 mm. Pen-up moves rise to z = 12 mm.

  4. Inverse kinematics

    Each sample (x, y, z) becomes four joint angles θ₁ to θ₄ using equations 1 to 5.

  5. Servo driver

    Angles map to PWM pulse widths on four channels at 50 Hz.
