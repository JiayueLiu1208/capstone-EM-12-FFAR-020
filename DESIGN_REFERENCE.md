# Robotic drawing arm: project site

Four versions of the same project site, each in a different visual style. In every one, a model of
a four-axis arm (turning base, shoulder, elbow, and a wrist that keeps the pen vertical) writes the
site title live in the hero.

| Page | Style |
| --- | --- |
| `src/portrait.html` | **Project site.** Real-Time Robotic Portrait Drawing System: plain white page, pink arm, gold ink, video, pipeline, vote + QR. Settings at the top of its script: `TITLE`, `VOTE_URL`, `SITE_URL`, `ARM_AT_TOP`. Media lives in `src/media/`. (`portrait-bottom.html` is generated by the build as the arm-below comparison.) |
| `src/apple.html` | Apple-style product page: title up front, then a black scene where the 3D arm (base at the bottom) draws a portrait once it scrolls into view. The picture is the `DRAWING` list in the page script: the robot's own path from `src/drawings/camera_path.csv` (`C03_Tousled_Hair.csv` is another one), converted with `node tools/csv2drawing.mjs <file.csv>`; `VOTE_URL` and `SITE_URL` sit beside it. |
| `portrait-3d.html` (generated) | The same page with a three.js hero: `src/arm3d.js` (engine, printed-arm model, overhead camera) and `src/hero-3d.js` (materials, light, shadows). Falls back to the 2D hero without WebGL. |
| `src/pink.html` | Pink and cute: a smiling pastel arm writes in pink marker on a polka-dot desk |
| `src/blueprint.html` | Engineering drawing sheet: plan view, live joint angles, side elevation inset |
| `src/workcell.html` | Industrial work cell: yellow arm light-painting the title as a long exposure |
| `src/bench.html` | Maker's bench: aluminium arm on a cutting mat, broad-nib ink, build notebook |
| `src/terminal.html` | Amber vector terminal: wireframe arm with a live G-code stream |

## Change the title

Each page has one line near the bottom of its script:

```js
const TITLE = 'Placeholder';
```

Visitors can also type any word into the box under the hero and the arm will write it.

## Build

```sh
node build.mjs
```

This inlines `src/plotter.js` into each page and writes two copies:

- `dist/site/*.html`: complete standalone pages for any static host (GitHub Pages, Netlify, …). Open `dist/site/apple.html` to view the main page.
- `dist/artifact/*.html`: fragments for the Claude artifact host (not committed)

## The arm model

All motion lives in `src/plotter.js`:

- **Stroke font** (`GLYPHS`): single-line letters on a 10-unit cap height, so the pen traces each line once.
- **Planner** (`buildPlan`): orders strokes, flips them to shorten pen-up travel, and builds a timeline.
- **Kinematics** (`ART`, `artSolve`, `artFK`): the arm's real dimensions and its inverse kinematics.
  Edit `ART` to match your build (link lengths, shoulder height, pen offset, lift height, park pose).
- **View** (`articulatedGeometry`): a plan view, seen from directly above. The elbow is a single hinge,
  so the base, both links and the pen always lie in one vertical plane. From above they form one
  straight line that turns with the base and shortens as the elbow folds.

The project details on the pages (specs, parts list, build log, team names, links) are placeholders
to replace with your own.
